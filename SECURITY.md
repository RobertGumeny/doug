# Security Policy

If you discover a security vulnerability in `doug`, do not open a public GitHub issue.

Please submit the report through GitHub's private vulnerability reporting flow:

- https://github.com/robertgumeny/doug/security/advisories/new

This route keeps the report private and notifies the repository owner directly.

The owner will acknowledge new vulnerability reports within 2 days.

When you file a report, include:

- A short description of the issue
- Steps to reproduce or a proof of concept
- The affected version, commit, or environment details
- Any suggested remediation or relevant context
